# Phone Case

A Next.js phone-case storefront landing page exploring responsive product presentation and reusable visual components.

[Live demo](https://jp-phone-case.vercel.app/)

## Local development

Run these commands from the repository root:

```sh
npm install
npm run dev
```

Available scripts:

- `npm run build`: `next build`.
- `npm run lint`: `next lint`.

## Main dependencies

`react`, `next`. See `package.json` for the full dependency list and versions.
